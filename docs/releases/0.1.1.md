# Clair and Obscur 0.1.1 preview

Four independent previews for ordinary Google Chrome and Equibop with Equicord. Clair is warm and light. Obscur uses deep neutral surfaces and restrained emphasis. Both share the Tornado Atlas palette identity.

This release completes the project introduction, installation and restoration guides, platform-specific download page and reproducible source archive. The page shows both palettes together and keeps native compatibility limits visible. Browser regression checks now exercise actual file downloads and static navigation without JavaScript.

## Downloads

- `Clair-Chrome-0.1.1.zip` and `Obscur-Chrome-0.1.1.zip` are native Chrome theme packages. Extract one and load its manifest folder in a separate Chrome test profile.
- `Clair.theme.css` and `Obscur.theme.css` are standalone Equicord themes for Equibop. Add them through the active Themes folder. Use native Light for Clair and Dark for Obscur.
- `source.zip` includes the generators, tests, research, documentation and preview source.
- `release-SHA256SUMS` verifies the six other release assets when saved together in one directory. `artifact-manifest.json` also records the generated package contents.

Follow the [installation and restoration guide](https://github.com/T92T1914/clair-obscur-themes/blob/v0.1.1/docs/installation.md). Preserve existing theme choices, QuickCSS, plugins and everyday Chrome profiles. Inter is installed separately. Native Chrome themes cannot change Chrome's interface font.

## Acceptance remains open

These are preview builds. Build validation and headless component checks do not establish actual Chrome frame behavior, Equibop compatibility, physical HDR appearance or reading comfort. Both appearances still require installation, switching and restoration checks in the target applications. No Chrome Web Store or Equicord library approval is claimed.

The themes contain no scripts, remote font imports or analytics. Display settings and color profiles are outside their scope. No reader extension is included.
