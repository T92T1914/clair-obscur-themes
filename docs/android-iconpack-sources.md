# Android component sources

The icon-pack artwork is the project's 0.22.0 Obscur drawing set. No upstream artwork or implementation code is imported. The original 1,295 component rows in `android/iconpack/components.json`, the four Gboard rows and 22 video-editor rows are selected from Lawnicons' `app/assets/appfilter.xml` at commit `c85fc8fb825228b021317f83c0a1a9f00b1c889d`. Eleven additional exact aliases have a separate launcher-observation source.

The [pinned upstream XML](https://github.com/LawnchairLauncher/lawnicons/blob/c85fc8fb825228b021317f83c0a1a9f00b1c889d/app/assets/appfilter.xml) is 3,344,113 bytes with SHA-256 `9b03e294aff3890e4e9b1e3d591c46c58b2be7d4ca140c5d56363494e127ffd6`. Its [Apache 2.0 license](https://github.com/LawnchairLauncher/lawnicons/blob/c85fc8fb825228b021317f83c0a1a9f00b1c889d/LICENSE) is included verbatim in the app, alongside an attribution notice identifying the selection and normalization. The original license SHA-256 is `c71d239df91726fc519c6eb72d318ec65820627232b2f796219e87dcf35d0ab4`.

The upstream rows retain the source lines, original component spellings and source element types. Relative activity names are expanded using their declared package. Component aliases remain opaque names, including aliases that do not look like Java classes. A malformed entry with an extra package/activity separator was rejected. No invented activity or package-only fallback fills an unmatched row.

The named package identities remain those in the existing icon catalog. The original selection yielded 1,153 aliases for 237 named packages. Fourteen public system-app package identities contribute another 142 aliases across 13 general functions. Named assignments take priority where a generic function overlaps a named app. For example, Google Messages keeps its named drawing while the generic messaging drawing targets Samsung Messages.

The 0.1.1 update retains every upstream row and adds 11 exact launcher aliases observed on October 21, 2026. These rows use `source_kind: "observed-launcher"` and `observed_on: "2026-10-21"`. They carry no upstream line numbers, original-component fields or source element types. The table's root `source` continues to identify only the upstream selection. The generator rejects mixed observation and upstream attribution, unknown source kinds and malformed observation dates.

The 0.1.2 update retains those 1,306 mappings and appends four exact-package Gboard declarations from upstream lines 7121, 7122, 7123 and 7126. The separate `.adobo` and `dev.jason` packages on lines 7124 and 7125 are excluded. The resulting 1,310 mappings contain 1,168 named-app aliases for 246 named packages, plus the unchanged 142 generic-function aliases. Twelve of the 258 named packages still lack a qualified mapping. Observations establish exact launcher identities at the recorded time. They do not prove the updated APK's recognition, a complete mapping result or permanent stability after application updates. An opaque alias was transcribed manually and remains subject to the repeated local coverage check. No full installed-app inventory, private evidence path or phone screenshot is included.

The 0.1.3 update preserves all 1,310 earlier mappings and appends 22 declarations for ten officially listed video-editing and motion apps. This gives 1,332 mappings, with 1,190 named-app aliases for 256 named packages and the unchanged 142 generic-function aliases. Twelve of the 268 named packages still lack a qualified mapping. Each new row retains the exact pinned source line and component spelling. No new launcher observation is claimed.

The retained 0.1.4 candidate uses the 0.21.0 drawing revision and makes no component-table change. All 1,332 mappings, their order, provenance and generic-package identities remain exactly those of 0.1.3. No new upstream selection or launcher observation is claimed. Artwork qualification, APK packaging and native assignment remain separate checks.

The 0.1.5 candidate uses the 0.22.0 drawing revision and refines four existing drawings without changing the component table. All 1,332 mappings, their order, provenance and generic-package identities remain exactly those of 0.1.4. No new upstream selection or launcher observation is claimed. The qualified artwork pin is separate from APK resource readback and native assignment.

Two retained declarations use the opaque activity names `com.jojoy.delegate.JojoyInstallerActivity` and `com.duapps.ad.DuAd` under their exact selected packages. They are historical upstream declarations. They do not establish that the current official application exports those activities, recommend an alternate build or installer, or cause this pack to execute an activity. The pack maps component names to drawings. Its public package queries include only the catalog's exact package identities and the existing verified generic identities.

Generic package identities were checked against official Samsung Galaxy Store detail records where available, Google Play records and Google's explicit Play Store package constant. Samsung's [F916U Android 11 application list](https://docs.samsungknox.com/CCMode/F916U_R.pdf) supplies historical identities for Weather, Gallery, Camera, Settings and Galaxy Store. This is a Galaxy Z Fold2 document, not a current phone inventory. Gallery and Camera store requests returned 404, as did the earlier Weather request. Those missing store records were not treated as successful current listings.

An upstream declaration can describe a historical app version, debug variant or component that is not currently a launcher entry. These facts establish a bounded starting mapping, not installation on a particular phone. The app's explicit local coverage check can identify visible aliases missing on a device after installation. Theme Park recognition and the applied launcher result remain separate native checks.
