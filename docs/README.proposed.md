# Clair and Obscur

Proposed README copy. This file is not the adopted project README or a published store listing.

Clair and Obscur bring Tornado Atlas's warm light and restrained dark appearance to ordinary Google Chrome and Equibop with Equicord. The aim is a readable everyday interface that still feels like the same family: warm surfaces and dark text in Clair, near-black layers and clear text in Obscur.

The project builds four native theme artifacts from one set of semantic colors:

- Clair and Obscur Chrome themes, with native browser colors and an original package icon.
- Clair and Obscur local Equicord CSS files, retaining the client's layout, scaling and controls.

Equicord uses installed Inter 400, 600 and 700 with genuine italic faces. Code, icons and other writing systems keep appropriate fallbacks. Native Chrome themes cannot change the browser's UI font, so Chrome retains its own typography. No theme downloads fonts, runs scripts or restyles arbitrary websites.

This is an initial preview. Generated packages and component fixtures are separate from native application acceptance. The four artifacts have not yet completed their actual Chrome or Equibop installation checks. Physical HDR appearance and reading comfort also remain unverified. See the [acceptance record](acceptance.md) before treating the preview as a tested daily-use theme.

Use [installation.md](installation.md) for matching native appearance modes, isolated Chrome installation, switching, conflict checks and removal. Clair expects native Light appearance in Equicord. Obscur expects a native dark appearance. Existing themes, QuickCSS, plugins and browser profiles should remain recoverable.

Build from the project directory with Python 3.11 or newer:

```powershell
python build.py --tokens tokens.json --output dist
python build.py --tokens tokens.json --output dist --check
```

This produces the four downloads, a file manifest and SHA-256 checksums. The check compares generated bytes with an existing complete output. It does not install or publish the themes.

The [design notes](design.md) explain the Atlas reference, shared tokens and deliberate platform limits. The [research](../research/research.md) connects original issue reports and user feedback to concrete checks for code, search, toggles and active tabs. The [publication notes](publication.md) distinguish local packages from directory acceptance and store review.

Original source and documentation are available under the [MIT license](../LICENSE). Inter is installed separately. There is no optional reading extension in this preview: Chrome's existing Reading mode must be evaluated before adding another tool.
