# Clair and Obscur icon artwork

The current 0.2.0 icon artwork contains 24 original functional drawings in both Clair and Obscur, giving 48 SVG masters. These are generic symbols for phone, messages, contacts, camera, gallery, settings, calendar, clock, files, notes, mail, browser, maps, music, video, store, wallet, calculator, weather, health, fitness, voice recorder, home and search. Choose the symbol by function when assigning it to an app. The set contains no app-brand logos or borrowed competitor artwork.

Version 0.2.0 strengthens the common stroke for small-size rendering, joins the message bubble and tail into one outline, balances contacts, music and fitness, and opens the browser, maps and calculator details. The original 0.1.0 SVGs, manifest and download archive remain available unchanged. This is a drawing refinement, not a correction established on a Samsung phone.

## Artwork and exports

The public preview's **Matching app icons** gallery shows the current artwork in both appearances, with visible labels and separate current and original SVG download links. The gallery and both downloads are included in the portable preview and remain available without JavaScript or a network connection. Each ZIP contains its 48 SVG masters, revision-specific manifest and the project license. The SVG checksum file identifies both actual archives. These vector downloads are separate from the prepared PNG packages and the PNG export command below.

`themeforge/icons.py` consumes the existing validated `tokens.json`. Each appearance uses `panel` for the tile, `text` for the main drawing and `accent` for emphasis. The two appearances share geometry. Each 512 by 512 SVG has a rounded 448-pixel tile and a transparent outer margin. Current strokes are 16 pixels, compared with 12 in the original set. At a 48-pixel specimen those widths become 1.5 and 1.125 CSS pixels. The drawings use local vector primitives, with no scripts, remote assets or fonts. Each SVG includes the project's MIT license.

The prepared raster exports contain 96 transparent PNGs: every master at 512 and 1024 pixels, plus two labeled contact sheets. Those dimensions and the rounded tile are project design choices. They are not documented Samsung import requirements or a guarantee of the phone's final mask. Function labels appear on the contact sheets and in SVG accessibility metadata. They are separate from the icon drawing and do not replace launcher app labels.

## Generate and check the masters

Run these commands from the repository root:

```powershell
python -m themeforge.icons --output outputs/samsung-icons-svg-01
python -m themeforge.icons --output outputs/samsung-icons-svg-01 --check
```

Those commands use 0.2.0. Add `--version 0.1.0` to both commands to generate and check the original artwork in a separate output folder. A check for one revision rejects the other revision's tree without changing it.

Generation requires a new directory outside managed `dist/`. An existing file or directory is preserved, including an empty directory. Linked or reparse-point paths and filesystem roots are refused. The output contains `Clair/`, `Obscur/` and `manifest.json`, which records each SVG's size and SHA256 alongside the generator and token versions.

`--check` compares every generated byte and the exact directory inventory without repairing it. Changed, missing or extra entries fail the comparison. Keep PNG exports and contact sheets in a separate directory so they do not become unexpected entries in the SVG tree. The Python generator produces SVGs and their manifest. It does not install a theme.

## Export phone images

The repository also provides an isolated PNG export command. It requires Python 3.11 or newer, available as `python` on Windows or `python3` elsewhere, the existing pinned Playwright dependency and installed Google Chrome in headless mode. Install the project dependencies with `npm ci --ignore-scripts --no-audit --no-fund`, then use the SVG directory created above:

```powershell
node tools/export-icons.mjs --input outputs/samsung-icons-svg-01 --output outputs/samsung-icons-png-01
```

This creates 96 transparent PNGs: every Clair and Obscur drawing at 512 and 1024 pixels. Paths follow `Clair/512/phone.png`, with the same structure for the other functions, size and appearance. The export includes the project license and an identity manifest. It creates no contact sheets and needs no installed font to render the drawings.

The exporter reads the input manifest's artwork revision and checks it against that exact generator revision before opening a browser. Both 0.1.0 and 0.2.0 are supported. Unknown versions, a changed version label or mixed artwork bytes are refused before output creation or browser launch. Changed, missing or extra input, links and junctions, an existing output directory, and output inside the input tree or managed `dist/` are refused. Use a fresh output path for each attempt. A failed or interrupted export preserves its partial output for inspection.

Rendering uses a disposable headless browser profile, keeps the sandbox enabled, mutes audio and blocks network requests. The manifest records input and output hashes, dimensions, pixel checks and the actual renderer identity. Every PNG is decoded and checked for its transparent margin and palette pixels. This verifies asset export, not installation on a Samsung phone. Browser versions can change raster bytes, so use the recorded renderer when comparing exports. The accepted 0.1.0 icon ZIP and its original PNGs remain separate.

## Conditional Theme Park use

Samsung documents app-icon customization through Good Lock's Theme Park and its Create Icon Theme feature. Its [official feature overview](https://news.samsung.com/global/exploring-good-lock-%E2%91%A1-unveiling-the-most-popular-good-lock-features) describes that capability, not a bulk import contract for this bundle.

On an installed version that offers individual icon-image selection, manually assign the chosen PNG to each app. Confirm that route on the actual phone before relying on it. Record the existing icon theme first, preview the result before applying, and retain the previous selection for restoration. Inspect the cover and inner screens, app drawer, folders, cropping and label readability. A preview sheet cannot establish any of those launcher results.

This delivery does not provide a ZIP bulk importer, automatic package-name mapping, an icon-pack APK or a Galaxy Store submission. Theme Park availability, image selection, masking and persistence remain specific to the installed One UI and module versions. No phone import, switching or restoration has been accepted.

## Fonts and validation

Launcher labels remain a separate setting. Samsung's [font-settings guide](https://www.samsung.com/us/support/answer/ANS10001360/) documents font style, size, bold and downloads through its font catalog, with availability varying by device and software. Inter availability on the phone is unverified. The icon bundle includes no font files and changes no system font settings.

The original 0.1.0 validation records remain historical evidence. Current checks cover distinct geometry, shared palettes, exact accepted original archive bytes, revision-specific admission, deterministic identities and preservation of existing output. Saved PNG checks inspect dimensions, transparency, palette and hashes independently of the SVG admission path. Actual 48- and 64-pixel comparisons in both appearances were visually inspected for stroke weight, clear joins and open interiors. These are desktop render and source checks, not a recognition study. Phone installation, launcher masking, label fonts and physical readability remain untested.
