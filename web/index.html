What happens if Inter is missing?

The preview and CSS use a system sans-serif fallback. No font is downloaded automatically. Install the official local Inter package for the intended faces.

Install with a way back.

Ordinary Google Chrome

  1. Create a separate, unsynced test profile. Keep your everyday profile and its theme unchanged.
  2. Extract the Obscur Chrome ZIP to a permanent folder. Open chrome://extensions, enable Developer mode, select Load unpacked, and choose the folder containing manifest.json.
  3. Check tabs, the toolbar, menus, focus and the new-tab page. Repeat with Clair, then switch back to Obscur.
  4. To undo it, use Settings, Appearance, Reset to default. Remove the development entry if it remains and return Developer mode to its recorded setting.

This is a developer installation. There is no reviewed Chrome Web Store listing yet.

Equibop with Equicord

  1. Record the current appearance, enabled themes and relevant font settings. Preserve QuickCSS and existing theme files.
  2. Use Equicord's Themes page to open the active themes folder. Add the downloaded CSS files without replacing another file or pasting over QuickCSS.
  3. Temporarily disable conflicting themes, enable Obscur and use native Dark. Check messages, inputs, settings, code, icons and focus. Repeat with Clair on native Light, then switch back.
  4. Disable the candidate and restore the recorded appearance and theme selections. Remove only the added CSS files when no longer needed.

Other theme or font plugins can override these styles. Stop and restore if an important surface becomes unreadable.

What the evidence covers

The shared palette is checked against its actual text and control-state pairings. Browser fixtures test local font selection, layout, keyboard controls, fallback and package downloads. These checks do not certify every surface in either host.

Chrome retains its own interface font and controls. The design target is a 4K OLED desktop with Windows HDR enabled, but the theme uses ordinary sRGB colors. It does not change brightness, calibration, color profiles or recording behavior. Screenshots do not establish physical luminance or reading comfort.

Actual theme loading, host interaction and physical reading acceptance are still pending for both appearances. Chrome's installed Reading mode must be evaluated before a separate reading companion is justified.
