What the evidence covers

The shared palette is checked against its actual text and control-state pairings. Browser fixtures test local font selection, layout, keyboard controls, fallback and package downloads. These checks do not certify every surface in either host.

Chrome retains its own interface font and controls. The design target is a 4K OLED desktop with Windows HDR enabled, but the theme uses ordinary sRGB colors. It does not change brightness, calibration, color profiles or recording behavior. Screenshots do not establish physical luminance or reading comfort.

Windows' normal Inter installation passed the strict six-face checks in fresh processes. Persistence after a later normal restart is still unverified. Actual Equibop settings supplied Inter Regular and Bold under both appearances, and the original configuration was restored. The other four faces, native code and language fallback, and broader client coverage remain open.

Obscur installed through Load unpacked in isolated ordinary Chrome. Clair installation, browser-interface checks, switching, Reset to default and test-profile cleanup are incomplete. Physical reading acceptance remains unverified for both appearances. See the dated acceptance record for the inspected scope.
