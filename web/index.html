Need PNG images for a phone?

The hosted preview can prepare a chosen 512-pixel PNG beside each icon appearance. This needs JavaScript and browser canvas support on HTTP or HTTPS. An extracted local-file preview retains SVG downloads and these source-export instructions. No icon is uploaded or installed by a PNG download.

For every icon at both 512 and 1024 pixels, the current source snapshot includes the existing PNG exporter and docs/samsung-icons.md. From that extracted source, generate a fresh SVG directory, then export it with the project's pinned Playwright dependency and headless Google Chrome:

python -m themeforge.icons --output outputs/samsung-icons-svg-01
node tools/export-icons.mjs --input outputs/samsung-icons-svg-01 --output outputs/samsung-icons-png-01

Use fresh output directories. The exporter produces every drawing at 512 and 1024 pixels and preserves existing output. The SVG artwork ZIP above is a separate viewing download; generate the exporter's exact input from source with the first command.

Actual image assignment depends on the installed One UI, Theme Park and launcher versions. Keep your current icon theme before trying individual PNG assignment. Check cover and inner screens, icon masks, cropping and app labels, then verify switching and restoration. There is no bulk ZIP importer or icon-pack APK. Launcher labels and fonts remain phone settings, and Inter availability on the phone is unverified.
